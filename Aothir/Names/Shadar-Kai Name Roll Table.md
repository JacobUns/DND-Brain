# About
- **Tone:** Somber, elegant, shadowed.
- **Style:** [[Shadowfell]]-influenced Elvish with sharp consonants and ethereal suffixes.
- **First Names:** Gothic and melancholy in tone.
- **Surnames:** Poetic expressions of death, grief, and silence (e.g., Thornmourne, Nightlament).
